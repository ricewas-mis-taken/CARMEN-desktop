# Carmen Focus (desktop)

Before starting any new feature, read [FEATURE_IMPLEMENT.txt](FEATURE_IMPLEMENT.txt) —
a checklist covering desktop core logic, the local API, Qt UI, chrome/firefox
extension parity, and cross-device sync, so a feature doesn't ship half-done
on one surface.

Before finishing any feature that involved a real design decision, add a
dated entry to [DESIGN_DECISIONS.txt](DESIGN_DECISIONS.txt) — an append-only
log of genuine architectural forks (not routine implementation detail) and
why one path was picked over another. FEATURE_IMPLEMENT.txt's own final
checklist step reminds you of this too.

Sibling repo: `carmen-extension` (C:\Users\Lucas\carmen-extension) has its
own copies of both files, kept in sync with these.
